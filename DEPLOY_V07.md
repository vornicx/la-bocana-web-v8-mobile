# Deploy v0.7

1. Sustituye el código del proyecto Vercel por este ZIP o súbelo al repositorio conectado.
2. Mantén las variables de entorno que ya están configuradas en Vercel.
3. No necesitas ejecutar SQL: `0006_admin_reservations_real.sql` ya está aplicada en el Supabase remoto.
4. Tras desplegar, entra en `/admin/reservas` con el usuario manager existente.

> Este ZIP contiene `.env` y `.env.local` porque se solicitó para las pruebas. Trátalo como privado y no lo publiques en un repositorio público.
